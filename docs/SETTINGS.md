# 功能与设置

设置会即时更新应用内预览；SystemUI 的实际效果取决于模块是否激活、固件是否匹配，以及最新配置是否收到回执。预览选择不会改变手机真实电量或网络。

## 图标组成

- 外圈约 240° 圆弧表示电量，暗色底轨保留；未知电量不编造进度。
- Wi-Fi 使用三道弧线与一个点，共四层信号等级。
- Wi-Fi 无互联网或需要登录时，整个扇形变浅，中间用满色大「!」「?」标出具体问题：
  浅色说明「是 Wi-Fi 的问题」，中间的大字说明「是哪种问题」。大字顶端盖过最外层弧线，
  底部落在扇形的信号点上，整段信号栈都被它压住，一眼就能看到问题出在 Wi-Fi 上。
- Wi-Fi 连接中时不再显示「...」，改为三条竖条依次上升的循环动画，直到连上为止。
- Wi-Fi 未连接时，中间一格按状态显示不同标记：

| 状态 | 标记 |
| --- | --- |
| 正常 | 网络类型 2G/3G/4G/5G |
| 仅紧急呼叫 | `SOS`（与 Android 状态栏一致） |
| 无 SIM 卡 / SIM 停用 / SIM 锁定 | 浅色 `sim` 字样 |
| 无信号 / 状态未知 | 两根等长的横条（占位标记） |

- 底部四点表示默认数据卡的信号，不额外显示第二组双卡信号。SIM 和飞行模式异常在此区域使用对应符号。开启“双卡信号环”后，改用电池环底部的两段同心弧段分别表示默认数据卡（外圈）与第二张卡（内圈），每段四点按信号强度点亮；漫游卡的点/弧段改用漫游色。
- 漫游时，右侧“R”标记与对应信号点/环段使用“漫游颜色”（默认蓝），与系统主色区分。
- 开启“显示上下行活动箭头”后，图标中下方显示一对上下箭头：下箭头代表接收（下行）、上箭头代表发送（上行），有流量时对应箭头高亮、无流量时淡显，便于一眼看出数据活跃方向（Wi-Fi 连接时取 Wi-Fi 活动，否则取默认数据卡活动）。
- 开启“反向布局（侧边徽标）”后，漫游“R”与 VPN 盾牌从右侧移到左侧，其余图形关于中轴对称不受影响。
- 充电闪电和充满对勾位于电量弧顶部，周围局部渐变虚化；插电未充电保留暂停标记。
- 正常图标跟随系统颜色；电池状态色优先级为充电/充满、严重低电量（默认 ≤10%）、低电量、省电、正常。数字和中心信号不强制变成充电绿色。开启状态颜色后，自定义颜色会按状态栏典型背景做可见性校正，保证对比度达标。
- 充电配色严格按「电池检测 app」的「快充模式」文本判定，不读瞬时功率、不猜硬件规格：快充模式为 SVOOC 或原装百瓦 UFCS 档位（`UFCS(120.00W)`，即合同功率上限 ≥100W）→ 紫；第三方 UFCS、PPS → 绿；PD、DCP → 蓝；普通、慢充 → 橙。第三方充电器绝不因功率高而显示紫色。
- **充满后跳橙属正常**：充满后系统会停止充电、快充协议归零，图标会从充电色短暂跳为橙色，随后恢复跟随系统色（原生图标此时则显示绿色后转黑，与三合一的橙↔黑跳变对应）。
- 检测到 VPN 连接时，电池环右上角显示盾形标记（可在设置中关闭）。

## 电量数字自动显示

“始终显示电量数字”与“低于阈值自动显示”互斥，开启一个会自动关闭另一个，也可以全部关闭。升级时若旧配置两项都开，保留“始终显示”，关闭自动显示。无论选择哪种数字模式，充电闪电和充满对勾均优先于数字。

以阈值 30% 为例：

| 真实状态 | 显示 |
| --- | --- |
| 电量 31% | 隐藏数字 |
| 电量下降到 30% | 显示数字 |
| 电量 29% | 显示数字 |
| 插电并开始充电，电量 ≤ 30% | 显示闪电 |
| 充电至 31% | 继续显示闪电 |
| 拔线，电量仍 ≤ 30% | 恢复数字 |
| 插电但暂停充电，电量 ≤ 30% | 显示数字 |
| 已充满 | 显示顶部对勾 |

数字占据顶部标记的位置，不额外增加图标高度；背景虚化随数字大小变化。非充电、非充满时才显示数字，必要时替代暂停标记，电量弧仍保留状态色。阈值设为 100% 也不会覆盖闪电或充满对勾。切换数字模式不清除阈值、字号或颜色设置。

自动显示依据当前有效百分比计算，不需要跨重启保存“曾低于阈值”状态。真实百分比未知时不触发自动显示；充放电状态未知但百分比有效时，仍正常判断阈值。

## 诊断与恢复

- “设置已保存”只证明本机保存成功；系统回执才说明配置已被读取。
- “恢复原图标”关闭替换，不清除全部外观参数。
- 顶部“恢复默认”会重置外观参数，并关闭系统替换。
- 底部“关于”显示实际安装版本；“作者主页”通过系统打开维护者的酷安链接。
- 日志提交与故障恢复见 [安装说明](INSTALL.md) 和 [适配边界](COMPATIBILITY.md)。
